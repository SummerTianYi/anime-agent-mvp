## 整合内容

保留 Claude、zcode 既有功能及贡献标记，保留 DS 文本主脑与 StepFun 视觉协作、工具权限、预合成、后台任务及最新会话/记忆 UI。Codex 补齐近期已在本地验证的以下实现及其回归代码：

- 告别请求关联动画和语音：短音频不再提前结束动画，正常长音频不被动画时长截断；无语音、失败或超过退出截止时间时有明确降级。
- TTS 正/负健康结果均使用短缓存，减少 sidecar 重启后旧状态造成的误判；不改变既有声线权重。
- Windows MCP 命令保留带空格、Unicode、引号和空参数的边界。
- Google Drive 兼容层向刷新流程传递 OAuth 应用身份；保留上游只读工具行为、MIT 版权和许可证。
- 问候开头的少量唤醒误听兼容，避免把普通“前一天”等日常词误当唤醒。
- 外置私有 Core 配置及现有热重载采用同一文件来源；显式 Godot 路径优先。
- 动作资源验证更新为已实装五动作的各自契约；补齐表情 GPU 对照工具。测试脚本不是用户数据。

本次没有修改官模、动作二进制、声线、正式数据库或当前角色窗口。既有历史贡献记录中的“未提交”描述当时阶段，不代表当前源码发布状态。

## 验证方式与范围

提交前使用 Mock、关闭真实语音/唤醒/外部 MCP、隔离数据目录验证当前源码；公开保留测试程序，不附内部原始日志、测试对话或账户文件。

当前自动基线为 Core 238 项、启动逻辑 14 项、TTS 生命周期 13 项、Drive OAuth 4 项；另检查文档一致性、前端构建、Godot 输入/动作/表情/告别与资产契约。准确命令及隔离要求见 [TESTING.md](TESTING.md)。GitHub 对每次 main 推送运行仓库现有 CI；本地结果不代替远程执行结果。

此前已在本机独立副本完成真实 CUDA 声线、原 CMD 启动/退出恢复、授权的 DS/StepFun 及只读 MCP 验证。这些是既有验证，不是在本次文档上传时重复访问真实账户。没有通过全新系统、第二台电脑、macOS 或无 NVIDIA 硬件的完整等效验收，也没有进行真实麦克风全流程验收，不能据此承诺任意故障零间隙恢复。
