## 修复位置与成因

- 在基准中，聊天分流、公开查询范围解析和待办撤回分别判读同一句原话。否认或暂停可能落到“待确认”的旧路径，车队榜即使被排除仍会命中字段规则，先命中取消的句子又可能直接返回，吞掉后半句的英超。六项在固定基准重放即可复现。[修前样本](before.json)
- `chat_channels.py` 和 `main.py` 保留对其他工具、真实确认和任务状态的路由。遇到公开对象、公开范围或相关待办时，Core 将完整原话、日期、上次公开范围和本会话的公开查询票号放入现有 `complete_with_tools` 流程。模型只收到一种公开操作提案工具。私人邮件待办及其正文不会进入提案上下文。原来的公开意图分句、查榜偏好和二次否定判断已移除。[分流](../../../services/agent-core/agent_core/chat_channels.py) · [Core 入口](../../../services/agent-core/agent_core/main.py)
- `public_query_turn.py` 校验提案模式、摘录、对象、允许字段、时间约束、票据唯一性及可见版本。宿主按原票据在既有账本取消，再为新读操作单独过权限。确认时使用已存参数。提案缺失、解析失败、指代歧义或票据已失效时，保留当前状态并澄清。公开对象、字段字典和时间格式继续用于能力发现和参数校验。`public_search.py` 继续负责验证公开请求、构造外发查询并交回现有答案链路。[提案校验](../../../services/agent-core/agent_core/public_query_turn.py) · [搜索出口](../../../services/agent-core/agent_core/public_search.py)
