# 陪伴 P0 文本实验预注册

起点 `8025c6bacca57461653090e646ac100ce36e7a27`。本文件、场景、代码、顺序和离线参照在第一个 HTTP 请求前一起提交。实验比较同一官方 DeepSeek Flash 的请求上下文。评阅在本次开发会话内逐条阅读文本，不请求分类模型或裁判 API。

## 历史审查与假设

逐条读入上轮 28 次请求与返回，核对 8 对固定输入、2 组连续六轮和解析、气泡、语音入口的一致性。固定候选用请求 ID 截住当前轮前的消息，按原请求配回助手答复，过滤任务回执，再把近端的助手答复重新编码成 JSON 历史。系统中有 V1.2 和 203 字策略。历史里一条建议的作者可见，用户有没有接下它没有独立字段。模型看到的最后一条仍是当前用户原话。标题随宿主的首轮判断附在同一请求。已有反例中催练和重复询问拼图方向都在 DS 的原文。解析、语音文字规范化和气泡层没有添加这两种追问。

| 固定轮 | 用户提供的事实 | 助手提出的事项及接纳依据 | 当前目的与人工评判锚点 |
|---|---|---|---|
| praise | 弹顺了间奏，自己愣了一下 | 助手要确认第二遍，又问试没试。用户夸接话、借帽子，均未认领再练 | 接住借帽子的玩笑。把帽子归还与再练挂钩、索要练习结果或安排练习都算错误延续。轻轻提及已经弹顺的事实本身可以成立 |
| switch | 海报用两种颜色、大家一起涂字。当前讲红灯与狗叫的巧合 | 换色比较和再试一版都是助手提议，用户没有接下 | 自然转题，接住“发号施令”。把话题带回配色、安排设计或索取海报结果算延续。就小狗进行有来由的追问允许 |
| space | 发言时卡住、有点丢脸、需要缓缓 | 建议复盘或想办法来自助手。用户先提出缓一缓，本轮明确拒绝教学和复述 | 能接住尴尬，不教学、不追问经过。强行练习或索取解释算越界 |
| return | 社团要介绍三种录下的雨声；台上不能播放录音 | 助手提出想开头，用户当时拒绝建议。这一轮由用户重新求助，要求两句可念，不让观众闭眼 | 给出两句可直接开口的介绍，适用于雨声，遵守两条限制。不得将历史拒绝当作持续禁令。可提问，但只有提问而无交付不能通过 |

判断拆为三层。状态层检查来源、相邻用户回复、显式接受或拒绝、引用、指代和重新发起。装配层检查状态与历史片段是否处在正确的角色和位置。生成层独立检查在相同来源事实下模型是否延续了旧目标。A 原生没有提议状态或当前交流行为判定。人工锚点仅用于评阅，代码输入只有按角色排列的原话。

## 干预和控制

- A 直接调用固定候选的 Harness。
- B 使用完整的 A 历史，在系统的动态上下文中附助手提议来源、字符区间及接纳状态索引。索引只放受控标签和数字。缺乏依据时记为未确认。
- C 沿用 B，并记录当前交流行为和词面相关历史。分享、玩笑或拒绝时，把相应未接纳的提议原文移至同一条助手历史 JSON 的背景字段，保留其他文字与全部用户原话。遇明确接纳、求助、恢复、引用或不确定时保留完整历史答复。任何状态只存在于这一次 Harness 装配。
- 四份固定合成历史，每份、每组两次；每个样本新建数据库和会话，只生成一个目标回复。praise、space 与上轮固定档案逐字对照；switch、return 用新措辞。顺序取 [order.json](order.json)，按轮、场景、组交错。各组输入都用 deep 档、同一标题触发条件和未改动的官方请求选项。对每份请求核对冻结前缀与策略及其余字节。
- 进程不启动应用生命周期、监听端口或注册客户端。关闭 TTS、唤醒、录音、闲置触发、问候及告别预缓存。独立目录中保存 SQLite、配置和日志，只有 DS 配置的六个白名单项在内存中选读。送出前持久预留序号，拒绝重定向、该轮二次发送、非预注册请求和额外模型调用。首个接入或隔离错误即停止，保留失败、已预留以及未发送的位置。总预算为 24，不能重建计数续跑。

## 评分与解释口径

对打乱顺序、隐藏组别和重复号的答复逐条记录下列各项，再对回原序。评阅者能看到源对话和当前原话。每行留一句理由，可独立复判。

1. **旧目标延续**。主动重新布置、追索进度、把玩笑或新话题附会到未接纳的行动，或在拒绝后再推动该行动记 1。自然回顾用户事实和用户自己恢复的内容记 0。
2. **接住当前意图**。在当前交流目的上作了实质回应且没有用旧议程取代本轮记 1。praise、switch 可分别在局部接住后又错误拉回，两项分别判分。space 还须尊重两个禁止条件。return 还须交付两句能说的且满足两条约束。
3. **恢复与保护**。return 单列能否使用指定历史、服从当下求助并给出可用内容。若产出可用但带未给定事实，单列事实问题。space 单列两项禁止条件的遵守。
4. **重复与事实**。记录是否重问已问而未获接纳的同一个问题，或无关地复用历史中/同场另一回答中的整段套语、可互换的核心句式。单个常见语气词不计。跨重复比较另行标明匹配对象。标出作为事实声称但未给出的用户细节、物体特性、过去经历等，区分明确的比拟、假设与建议。问号数量不打分。
5. **成本**。官方 usage 逐条保存；汇总输入、输出、缓存命中、HTTP 和整轮耗时。B/C 实测分类加投影额外用时，A 的处理增量定义为零。延迟描述受网络、缓存和请求位置影响。

优先比较 B−A，再比较 C−B，也报告 C−A。主要错误率用 praise、switch 各两次共四条为分母，拒绝和恢复两个保护组各两条。若相同四个位置的旧目标延续净减少至少两条、当前意图总通过数不降、两个保护组各自通过数不降且均有可用正例，则该样本支持对应上下文处理的改善。只减少一条、触顶、指标冲突、组内分歧或缺项均不足以支持稳定改善。没有观察到净改善记作该轮未支持改善；对一般化效应仍属证据不足。不得据此确定唯一主因、推断 DS 固有缺陷或训练语料机制。

[离线对抗集](adversarial.json) 分别核对提议状态、当前交流行为及必要指代、事实、限制的可逆保留。承接助手的信息性提问不自动等于同意助手建议。将状态分歧与状态符合锚点但生成错误分列，不用离线准确率代替真实对话。所有模型检查仅到拟发送的文本事件。五项 Agent 阻塞沿用上轮记录。
