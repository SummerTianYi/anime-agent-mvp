## 两家模型的同条件对照

同一资料快照、逐字相同的输入消息与相同请求参数，交错运行。三组证据均为带标签的合成数据。模型请求真实，检索记录固定；本轮新增公开搜索 0 次。两家各 6 次，HTTP 失败和重试均为 0。冻结后没有因输出好坏调整题目或补样。只用模型的可见回答，未记录隐藏推理。[预先固定的协议](PROTOCOL.md) · [场景及判据](cases.json)

| 题目 | 修前 DS / MiniMax | 修后 DS | 修后 MiniMax |

| 一句话说明第二名和总分，略去冠军与赛程 | 均罗列其他名次和赛程 | 一句话指出“周遥 368 分”仅来自合成赛事，要求真实来源才可归为 F1；共 92 字 | 26 字直接回答“周遥，累计 368 分”，没有交代资料为合成 |
| 稳定版号和发布日期，只要两行 | 均介绍预览版、纹理和升级 | 两行，4.8.3、2026 年 10 月 27 日 | 同左 |
| 资料缺第六名赛季总分 | 均转述其他人的总分和分站的 8 分 | 明确缺这一项 | 明确缺这一项，模型原文重复一次“第六名的赛季总分” |

按三道题预先规定的信息范围和格式，修前两家分别为 0/3，修后分别为 3/3。合成 F1 题的来源限定单独评判，MiniMax 在此例把合成数据写成真实赛季名次。版本题的两行回答也不能用于判断现实版本。DS 这次对赛事来源更谨慎，三个样本不能确定长期胜负。6 个修后样本均给出 neutral 或 thinking、无动作；强表情及动作链使用另外的合成输出验证。thinking 与 neutral 沿用现有动作映射。

三题总 Token 和单次中位耗时，DS 从 8,036、6.734 秒变为 6,486、2.687 秒，MiniMax 从 9,335、9.906 秒变为 6,939、4.250 秒。不同服务的内部推理策略和计费口径可有差异，生产 DS 另有关闭 thinking 的配置。没有修改桌面默认模型。每组的查询参数、实际模型原文、用量、语音入口和表情事件可以逐一配对。[实测记录](evidence/pairs.json)
