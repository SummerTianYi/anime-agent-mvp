# 洛天依 V1.2「亲密自然 × 可爱灵动」人设候选

日期：2026-11-07。基线：`783472060a52aae5e745ca60077347eb0943f184`，从 `codex/root-cause-repair-batch01-followup-20261012` 创建独立 `codex/persona-v1-2-companion-20261107` 分支。用户批准按亲密自然型、可爱俏皮的15岁洛天依角色气质更新完整系统提示词，并交付 GitHub 验收。

## 本次精确范围

- 只改 `services/agent-core/agent_core/harness.py` 中的 `ROLE_PROMPT` 与 `RUNTIME_CONTRACT` 两个字符串；不改 Python 可执行逻辑。
- `【稳定身份】`：温柔仍为底色，增加15岁**角色设定**的青春气息、好奇、爱笑、俏皮、适度害羞和小得意；避免固定语气词和持续卖萌。
- 新增 `【关系与陪伴】`：自然亲近、双向话题、适度玩笑和情绪收放；仅依据实际对话/宿主记忆延续过去，不编造共同经历，不默认恋爱、不施加陪伴压力。
- `【表达与人物表现】`：聊天可以接梗、表达联想和留白；情绪低落时先倾听，严肃任务时清楚准确；不增加无法执行的承诺。
- 完整**静态**系统提示词逐字快照：[ACTIVE_PROMPT.txt](ACTIVE_PROMPT.txt)。它恰为 `ROLE_PROMPT + "\n\n" + RUNTIME_CONTRACT`，不包含每轮动态追加的任务、权限、记忆、工具和歌曲资料。

## 修改前后可见差异（非模型实测）

| 场景 | 原倾向 | V1.2 预期方向 |
|---|---|---|
| 用户分享好消息 | 温柔地祝贺 | 开心、惊喜、适度兴奋，也能保留简洁 |
| 用户开轻松玩笑 | 客气回答 | 接梗、轻微害羞或小得意，不机械撒娇 |
| 用户难过 | 安慰后立刻建议 | 收起玩笑，先倾听，允许不提建议 |
| 已有明确回忆 | 泛泛关心 | 仅在真实召回时自然延续话题 |
| 没有相关记忆 | 容易制造“熟悉感”的压力 | 不虚构上次发生的事，不声称在观察用户 |

## 不变的正式合同

- `TASK_DECISION_CONTRACT`、`TOOL_GUIDANCE`、`BASE_SYSTEM_PROMPT`、输出字段和允许的 emotion/gesture 枚举均未修改。
- 权限、ActionLedger、工具调用、记忆保存/更正、Provider、prompt 动态组装、Core/Godot/TTS 代码及任何正式配置/数据库均未修改。
- 启动/闲置/告别仍由 `main.py` 中固定台词控制；TTS 合成接口仍以文本/语速为主；这次**没有**实现主动情境个性化或情绪声线调制。
