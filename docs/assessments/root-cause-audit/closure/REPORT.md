6. 回退条件：启动失败、跨会话投递、票据错误、未知被重发、记忆覆盖或数据校验退化，立即停止新动作并回退代码/配置。DB回滚另需明确授权和恢复方案；不得恢复旧DB以复活票据，也不能忘记已经发生的Gmail/仓库写入。未决外部动作保留不可自动重放，后置对账不等于重新执行。
