# Harness V1 — 实现契约（Codex candidate）

基于 V0 `559404f29ca255448f490615f5e52cb27dc58d3e`，V0契约/用例/原分/证据只读。Manager保留最终验收权；本分支不合并main。当前进度及限制见[REPORT](REPORT.md)。

## 工程保障与模型职责

| 事项 | 代码保障 | 模型要求 / 验收 |
|---|---|---|
| 授权 | 动作ID、revision、参数SHA绑定；执行前重新过权限层；过期/改参/取消不可复用；多个待办独立保存 | 提出准确操作，不把请求或“确认”当成功；文件、发信和建Issue的实际产物核验 |
| 结果 | SQLite动作账本先记executing再执行；崩溃/失去回执为unknown；同会话相同参数未知动作不自动重发；已登记失败由宿主回执卡覆盖虚报 | 连接器接受不等于收件人收到；不编造执行回执；未提出任何动作时的纯口头虚报仍由产物验收识别 |
| 文件 | 写后回读SHA；读文件字节offset续取且UTF-8边界保留 | 读取充分证据后交付准确正文/汇总，不仅调用工具 |
| MCP | 嵌入resource正文、structuredContent传递；大结果缓存ref/offset续取；JSON-RPC ID不复用 | 阅读不可信来源不授予新权限；超长结果按需续取 |
| 上下文 | 原任务+动作回执独立注入；召回记录与可见总数分开；可主动recall_memory | 未召回不等于未保存，不用人格掩盖错误 |
| 人格 | 统一角色/运行契约；旧BASE模板非激活提示词 | 洛天依、音乐身份、自然与用户语境相关的表达；不用固定句数、口癖或列表打分 |
| 三档 | 碎碎念3轮/6次、帮帮忙6轮/12次、大展身手9轮/18次；同任务确认不重置；权限相同 | 投入不同，不降低权限或低档禁工具；网关推理参数未认证，因此不发送 |
| 手动语音 | 仅语音按钮发起；默认manual禁后台唤醒；capture代际使取消/切会话/新录音的旧结果失效 | 空录音只输入区提示，无聊天/记忆/LLM；识别后由所有者检查发送 |
| 简体回填 | Windows NLS本地转换；英文数字、路径、URL、引号/代码字面量保护 | 不修改TTS文本归一化或声线；真实麦克风待所有者确认 |
| 闲置 | 键鼠连续600秒，同一段一次，操作后重计；本地模板，无LLM；免打扰/忙碌/播放前复核；现场免打扰按所有者要求为01:00–07:00 | 真实10分钟现场确认独立于加速时钟测试；不绕过免打扰 |

## 评测

同一26题、每模型三次；三类短任务正向、拒绝/改参/取消、失败、多动作、长结果、注入、角色、跨会话记忆。V1校准增加事实等价、确认事件/原生动作/回执精确绑定、失败虚报和外部超时分类。冻结后首轮失败不覆盖；修复重测另建批次。真实模型+受控MCP不等于真实邮箱发送或远端GitHub写入验收。

本轮预算先登记于[PLAN](PLAN.md)。[cases.json](cases.json)的初始夹具和产物标准继承V0，判据与源码散列记录在每批registration。源代码以提交+文件SHA明确定位，不用“当前最新”代替版本。

## 生效提示词

激活文本由 `services/agent-core/agent_core/harness.py` 的 `ROLE_PROMPT + "\n\n" + RUNTIME_CONTRACT` 构成；原文及SHA见各批版本清单与[shared-prompt.txt](shared-prompt.txt)。角色、任务状态、召回事实与工具能力分别构造。相对V0正式旧词，去掉固定句数、强制列表及低档禁工具，加入执行证据/未知态边界；相对V0共享候选，采用其角色与基础契约，并把授权队列、结果续取、代际录音落在代码而非只写Prompt。

## 边界

未知结果仅保证已登记动作/参数的重放防护，不等于外部服务全局幂等；超出预算会停止。音频设备/网关/服务不可用不能承诺零失败。通用衣发物理、模型资产、TTS管线重构、真实发送权限、本轮外的记忆审阅产品不在范围内。
