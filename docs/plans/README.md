维护日期：2026-09-10；本次整合：Codex，依项目所有者要求。本文是所有 agent 共用的长期规划正文，打开 GitHub 的 `docs/plans/` 即可阅读；不再按 agent 各建一份有效路线。原作者和后续实施者分别记录，整合文档不等于取得其他人的工程贡献。

## 1. 目标、阅读与维护约定

最终产品是一个本地优先、角色优先、安全优先的洛天依桌面伙伴：有可辨识的形象、自然动作与声线，能聊天、记忆、感知，并在授权范围内做事；不是把通用聊天窗口换一张头像。模型、动捕、Agent、语音、UI、稳定性和分发属于同一产品的不同方向。本文管理“以后做什么、为什么做、怎样验收”；[HANDOFF](../HANDOFF.md) 管当前领地和运行状态，[TESTING](../TESTING.md) 管实际测试命令，[CONTRIBUTIONS](../CONTRIBUTIONS.md) 管贡献凭证，[模型版本索引](../../model-versions/README.md) 管不可变交付。

所有 agent 新增长期提议、改变方向或完成里程碑时，只在本文相应章节更新；不向旧入口或历史档案追加新规划。每项至少记录 ID、目标/方案、原提出者、实施者或待认领、状态、依赖/待决策、验收标准和证据。原提出者不随接手而改变；未知归属写“待核实”，不猜。候选方案不是执行授权，未排期不是默认同意开工；新增方向和重大改线由所有者决定。

状态统一为：已验收、部分完成、待实施、待决策、暂缓、历史撤回。标为已验收必须附证据与适用范围；本地改完、提交、推送、CI、视觉验收分别记录，不相互替代。以下状态依据迁移时仓库文档和已确认提交整理，不是重新运行全部能力的验收；并行 agent 的未提交工作不自动算已发布。若本文与较新的代码/交接记录矛盾，先核实具体提交再回写，不凭旧表重做冻结能力。

### 官模与版本门禁

原 GLB 为 128,621,144 字节，SHA-256 `DF55806D343D149B41C20D0EF074373CAFCA2379212FD8691E998EA6CDDC6E4A`；Blender 源场景 751 骨，Godot 导出骨架 703 骨，不混用计数；48 个表情槽、两条完整 17 骨长马尾链。默认保护网格、拓扑、骨架、权重、UV、纹理、材质槽、标志性元素与比例。所有者曾允许评估五官几何调整，但实际采用的 1.4 是材质方案；后续几何改动仍须说明范围并获得批准，只做派生版本，不覆盖官模。

每轮先验证旧快照，同相机、同姿态、同尺寸、同灯光做 A/B；至少覆盖正面、左右、背面、最大缩放、中性脸、极端表情，并检查动作与输入不回退。纯材质轮要求几何/变换不变、Alpha 轮廓一致，不用“不到 1%”掩盖身体变形。失败候选不替换正式版；通过技术测试后由所有者看图，批准实装后重启 Avatar 并核验实际版本。若当次只要求试渲染，不提前实装。

每个正式版保存独立本地 Blend/GLB、运行时提交、哈希、配置和预览；1.4 起另冻结动作/支持纹理与恢复测试依赖。完整回溯走 [隔离版本 worktree](../../model-versions/README.md)，不只是切材质开关；旧版 1.0–1.3 的支持资源仍受原清单边界限制，不能声称已补成 1.4 级独立档案。原资产与派生纹理不公开上传，仅提交定位、哈希和复现说明。默认不做减面/重拓扑、AI 覆盖官方设计、离轴移动人物或用 FXAA 代替高清采样。
