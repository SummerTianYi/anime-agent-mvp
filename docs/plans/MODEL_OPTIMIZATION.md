下一阶段直接做小幅、少接触动捕：保留双臂斜下外展，先点头、左右看、轻微重心移动。贴腿待机、裙装碰撞、复杂旋转自然性、连续高清录制、自适应画质仍未完成；不能把本轮通过当成这些专项的验收。

## 约束与基线

本项目的“优化”默认只允许改变运行时渲染、外部材质覆盖、派生纹理、相机、灯光、动画曲线和性能策略，不直接改写官模 GLB。当前权威基线为 128,621,144 字节、SHA-256 `DF55806D343D149B41C20D0EF074373CAFCA2379212FD8691E998EA6CDDC6E4A`、751 根骨骼、48 个表情槽和两条各 17 骨骼的长马尾链；每轮优化都必须先后核对这些事实。原始网格、拓扑、骨架、蒙皮权重、UV、形态键、材质槽、纹理和角色标志性元素不得被覆盖，任何派生资产都必须能一键关闭并回到官模基线。

## 明确不采用

| 操作 | 原因 |
|---|---|
| 对官模执行 Decimate、重拓扑、合并材质槽或应用破坏性修改器 | 会改变轮廓、拓扑、权重或官方结构，收益与风险不成比例 |
| 直接用 AI 重绘结果覆盖官方脸、服装或纹理 | 容易改变角色设计和标志性元素，且难以逐像素回退 |
| 为适配桌面位置移动 3D 模型离开相机光轴 | 已验证会造成离轴透视变形；桌面移动必须发生在二维合成层 |
| 用 FXAA 作为主要清晰度方案 | 低分辨率下容易变糊；当前优先超采样和 MSAA |
| 将模型、纹理、Blend/PMX/VRM 或派生高清包提交到公开仓库 | 文件体积与再分发授权边界未解决 |

## 1.2 外部调色与立体感版（Codex，已验收）

Godot 实际导入结果解释了 1.1 “清晰但偏亮、偏平”的根因：23 个表面均为 `StandardMaterial3D`，颜色纹理挂在 `emission_texture`，基础色为黑且自发光倍率为 1，因此场景主光和补光很难形成体积。1.2 不编辑官模或纹理，而是在运行时复制 10 个目标表面，用同一张官方纹理同时驱动低权重 Toon 漫反射与保底自发光；脸、身体、手、腿作为连续肤色整体处理，前发、后发、两条长马尾整体处理，主服装、辅服装和裙装整体处理，眼睛、表情叠片、饰品和透明翼保持原材质。`ANIME_AGENT_MODEL_LOOK=1.1`、`baseline`、`off` 或 `false` 可精确恢复 1.1；`1.2`、旧别名 `1.2-preview` 或留空均启用当前正式效果。

## 版本冻结与对比

正式模型版本由 `model-versions/index.json` 管理，受限的 Blend/GLB 保存在仓库同级 `model-archive/<version>`。当前 `1.0` 是优化前正常比例基线，`1.1` 是固定光轴高清版，`1.2` 是外部 Toon 调色与立体感版；三者模型二进制相同，视觉差异来自 Git 运行时提交，因此完整对比必须使用 `open-model-version.ps1` 创建隔离 worktree。下一轮优化开始前先运行版本校验，验收通过后使用 `snapshot-model-version.ps1` 连续分配 `1.3`；失败或未验收实验不得覆盖快照、不得占正式版本号。字段、截图要求和切换命令见 [`model-versions/README.md`](../../model-versions/README.md)。

## 历史试验记录：高清输出与边缘诊断（Codex，2026-09-08，后纳入 1.3）

## 历史试验记录：1.3 材质候选 A（Codex，2026-09-08，后获批准）

依所有者最新要求，先用独立 `apps/avatar-runtime/lookdev/` 脚本做同帧 A/B；正式运行材质仍是 1.2，不自动重启/实装。候选只复制十个材质，将 Toon 受光/高光改为柔和 Burley / 低强度 GGX，并分组调整肤色、头发和衣服的受光/自发光比例；不改灯光、相机、纹理、MSAA 或官模结构。它是日常观感的材质精修试验，不是已完成全部边缘/性能优化的正式 1.3。七组对照图加十二个待机时刻/朝向用于检查比例/轮廓一致性；比较图两侧统一使用当前保守待机而非历史截图。实现、参数、重现命令、指标含义和失败路径见 [候选说明](../../apps/avatar-runtime/lookdev/README.md)。是否更好由所有者看图验收；未通过不冻结、不覆盖 1.2。
