# 官模非破坏性优化路线

## 约束与基线

本项目的“优化”默认只允许改变运行时渲染、外部材质覆盖、派生纹理、相机、灯光、动画曲线和性能策略，不直接改写官模 GLB。当前权威基线为 128,621,144 字节、SHA-256 `DF55806D343D149B41C20D0EF074373CAFCA2379212FD8691E998EA6CDDC6E4A`、751 根骨骼、48 个表情槽和两条各 17 骨骼的长马尾链；每轮优化都必须先后核对这些事实。原始网格、拓扑、骨架、蒙皮权重、UV、形态键、材质槽、纹理和角色标志性元素不得被覆盖，任何派生资产都必须能一键关闭并回到官模基线。

## 当前已完成

| 层 | 实现 | 结果 |
|---|---|---|
| 桌面合成 | 工作区大小的透明穿透画布；3D 模型固定在相机光轴，渲染到 1520×1840 SubViewport，再缩放为 760×920 二维透明层 | 保留原透视，解决离轴“压扁”和旧 560×760 裁切 |
| 清晰度 | SubViewport 2× 超采样、4× MSAA、高 DPI | 原型轮廓比例差 0.196%，遮罩重合度 98.36%，平均 7.99 ms/帧 |
| 光照 | 外部环境、主光和补光独立于模型文件 | 白色服装过曝降低，官模材质和纹理未改写 |
| 完整性 | `verify_desktop_canvas.gd`、动作/输入回归和本地资产契约 | 最大缩放无裁切，官模哈希、骨骼、表情和动作桥保持稳定 |

SubViewport 作为独立渲染目标并通过 ViewportTexture 合成、以及每个 Viewport 单独设置 MSAA，都是 Godot 官方支持的路径；材质增强应使用实例或表面级覆盖资源，不应回写模型内材质。参考 [Using Viewports](https://docs.godotengine.org/en/stable/tutorials/rendering/viewports.html)、[SubViewport](https://docs.godotengine.org/en/stable/classes/class_subviewport.html) 和 [Standard Material 3D](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html)。

## 后续方向与优先级

| 优先级 | 方向 | 非破坏性方案 | 预期收益 | 风险与验收 |
|---|---|---|---|---|
| P1 | MMD/二次元材质还原 | 建立独立 `.tres` 材质映射，按材质槽在运行时复制并覆盖参数；加入可关闭的 toon ramp、轻微 rim light 和轮廓 Next Pass，不写回 GLB | 面部、头发和服装层次最明显提升 | 逐材质截图对比；透明发片排序、眼睛和白色服装不得异常；关闭开关后像素回到基线 |
| P1 | 色彩与灯光标定 | 固定正面/侧面/背面三组灯光快照，按肤色、白衣高光和头发暗部调节环境能量、曝光与色温；配置放在场景或外部资源 | 增强体积感，避免再次“发扁”或过曝 | 三视图直方图和视觉门禁；不烘焙进纹理，不修改法线 |
| P1 | 高清截图/录制模式 | 保持日常 2×，截图或录制时临时切 3×；根据 GPU 帧耗时自动回落，提供 9:16 与透明背景预设 | 手机录屏、截图和特写更清楚 | RTX 5060 上日常目标 ≤16.7 ms/帧；切换不能改变相机透视或角色屏幕位置 |
| P2 | 派生高清纹理包 | 原 2K/4K 纹理只读保留；对脸、头发和服装分别生成本地派生 PNG，做边缘保护、去压缩噪声和人工抽检，再通过 Godot 外部材质引用 | 改善近景纹理模糊 | 不改变 UV、配色、图案、徽记和线稿；派生包本地保存且可关闭，不进入公开仓库 |
| P2 | 透明发片与边缘质量 | 按材质槽检查 alpha scissor、depth pre-pass、双面和排序；只改运行时材质参数 | 减少头发边缘锯齿、黑边和穿插闪烁 | 前后左右旋转测试；不能牺牲马尾层次或产生错误遮挡 |
| P2 | 表情与口型细化 | 继续使用现有 48 个形态键，通过时间曲线混合眼睛、眉毛、嘴型和眨眼，不创建替代脸型 | 提升角色生命感 | 每个表情回零后必须恢复官模中性脸；禁止永久写入形态键基值 |
| P2 | 马尾/衣摆二级运动 | 在现有骨骼上增加可配置阻尼、惯性、重力和碰撞近似；参数化并提供禁用开关 | 转身、待机和互动更自然 | 两条 17 骨骼链连续，不能穿胸、穿臂或改变静止基准姿态 |
| P3 | 自适应性能 | 根据平均 GPU 帧耗时在 1.5×/2×/3× 渲染倍率间切换，暂停不可见 Viewport 更新，保留 4× MSAA 上限 | 笔记本续航与高画质兼顾 | 切档无尺寸跳动；不得通过网格减面或删除骨骼换性能 |

## 明确不采用

| 操作 | 原因 |
|---|---|
| 对官模执行 Decimate、重拓扑、合并材质槽或应用破坏性修改器 | 会改变轮廓、拓扑、权重或官方结构，收益与风险不成比例 |
| 直接用 AI 重绘结果覆盖官方脸、服装或纹理 | 容易改变角色设计和标志性元素，且难以逐像素回退 |
| 为适配桌面位置移动 3D 模型离开相机光轴 | 已验证会造成离轴透视变形；桌面移动必须发生在二维合成层 |
| 用 FXAA 作为主要清晰度方案 | 低分辨率下容易变糊；当前优先超采样和 MSAA |
| 将模型、纹理、Blend/PMX/VRM 或派生高清包提交到公开仓库 | 文件体积与再分发授权边界未解决 |

## 每轮验收门禁

| 门禁 | 通过条件 |
|---|---|
| 文件完整性 | 官模字节数和 SHA-256 不变；本地派生资源有独立清单与开关 |
| 结构完整性 | 751 骨骼、48 表情、两条 17 骨骼马尾链、材质槽和动画绑定不减少 |
| 视觉一致性 | 正面/侧面/背面、中性脸、最大缩放和极端表情均有基准图；轮廓比例变化默认 <1% |
| 运行稳定性 | 输入、聊天、动作、旋转、缩放、穿透和位置恢复回归通过，无新增 Godot 错误 |
| 性能 | 日常档目标 ≤16.7 ms/帧；超限时降低派生效果或渲染倍率，不破坏模型 |

推荐下一步先做 P1 的“外部 toon 材质试验场”，只选脸、头发和白色服装三个材质槽，在独立开关下进行 A/B 截图；通过后再扩展到全身。该路径视觉收益最大，也最容易证明没有修改官模。
