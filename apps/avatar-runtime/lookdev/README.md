# Codex：1.3 材质 A/B 验证入口

所有者于 2026-09-08 先批准模拟、随后认可候选 A 并授权设为当前外观和推送。材质参数已原样提取至 `../model_look_v13.gd`，正式运行时默认选择 1.3；本目录仍只是离线验证入口，不被启动器调用。执行 `Godot_v4.7.2-stable_win64_console.exe --display-driver windows --path apps/avatar-runtime --script res://lookdev/render_candidate.gd`，输出位于 Godot 用户目录 `lookdev-1.3-candidate/<时间>-<进程号>/`（保留原诊断目录名），每次新建目录、不覆盖历史图。输出包含版本归档要求的七类 PNG、额外对照和 report.json。

| 项目 | 试验内容与边界 |
|---|---|
| 材质 | 复制 1.2 的十个材质实例；连续肤色、前后发及完整长辫子、主辅衣服及裙装分组调整受光/自发光比例、粗糙度、低强度高光和轮廓光；Toon 受光改为 Burley，Toon 高光改为低强度 GGX。参数在 `../model_look_v13.gd`；测试通过生产 `set_model_look_version()` 切换，逐参数核对与已认可的候选一致。 |
| 保持 | 相同官方纹理、网格、骨架、蒙皮、形态键、透明模式、相机和两盏灯。眼睛、饰物等其它十三个材质槽不动；不新增阴影、描边、纹理、抗锯齿策略或物理系统。 |
| 公平对比 | 左侧 1.2 材质，右侧 1.3 候选；两侧使用当前保守 A-pose 待机的同一时刻，1920×2320、4× MSAA、同光照/相机。正面为当前允许的最大缩放，另有基础距离视图。不是旧截图与新截图混比，不是完整历史运行时 worktree 对比。局部图为两侧相同区域的原像素裁切。 |
| 隔离 | 测试专用子类仅初始化必要模型/动作逻辑，不执行生产 `_ready()`，不启动 Core、MCP、语音、UI，不读写桌面位置或启动截图。当前桌面天依和其它代理均不重启。 |
| 检查 | 九组视图/表情、十二个待机时刻与朝向组合；材质开关前后比较 703 骨姿态、相机/FOV、网格 AABB、灯光；全图包围框一致，Alpha 在 2 像素网格上比较；回退 RGB 平均误差 <0.000001。负对照故意改变测试图 Alpha 和模型位移，确认门禁能够识别；覆盖 1.1/1.2/1.3/空值/旧别名选择。GLB SHA 前后相同、23 槽/48 表情/两条 17 骨链不变。 |
| 性能与局限 | 新增 RenderingServer 单个 3D Viewport 的 GPU 渲染计时，两轮 1.2/1.3 各采 60 帧，P95 <16.7ms 才通过；墙钟间隔另外记录，会受离屏后台节流影响。GPU 渲染时间不等于完整桌面端到端帧耗时。本门禁不是防穿模验收，也没有证明消除所有动态闪烁。 |

本轮收益预期是发束与衣服明暗过渡的小幅改善，而非换脸、重绘或显著增加几何细节。实际观感以 A/B 为准，允许所有者拒绝整个候选。采用 Godot 官方 [BaseMaterial3D](https://docs.godotengine.org/en/stable/classes/class_basematerial3d.html) 的既有材质参数，没有加入自定义渲染器。

测试过程曾遇到 Godot 不允许隐藏主窗口，随后最小化又让 `frame_post_draw` 停止；仅终止已确认的本轮测试 PID 21808，改为小尺寸离屏诊断窗口后完成渲染。生产 Avatar PID 55816 未终止。早期输出目录保留为试验记录，最终图以最新通过的 `report.json` 为准。
