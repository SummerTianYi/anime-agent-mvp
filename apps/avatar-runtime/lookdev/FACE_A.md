# Codex — face A offline study (2026-09-10)

Current status (Codex, 2026-09-10): owner approved A2; integrated as local default look 1.4 after expression regressions and restarted Avatar. Historical A1/A2 preview records below remain unchanged. Official model, source atlas, motion, Core, TTS and UI are unchanged; no commit/push. Formal freeze is pending: see `model-versions/PENDING_1.4.md` for evidence, backup and rollback.

`render_face_a.gd` reuses the existing `OfflineRuntime` inspection harness without its production `_ready()`. It duplicates only the face StandardMaterial3D and adds `face_a.gdshader` as a next pass. The shader samples the original face atlas read-only and adds bounded UV-attached warm shading at the nose tip, existing lip pigment and ear island. It does not write vertices/normals, replace textures, move hair or alter eye materials. These are stylized pigment cues, not newly simulated shadows or a geometric nose enlargement. It remains A, not the separately proposed geometry-editing B.

Run from the repository root with the existing Godot executable: `../tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --display-driver windows --path apps/avatar-runtime --script res://lookdev/render_face_a.gd`. Each run uses a new timestamp/PID folder under `user://lookdev-face-a/`. Images are actual OpenGL renders, not generated illustrations. Within each pair camera, lighting, pose and resolution are identical; closeups use 1200×1200, the small desktop example 560×760, both 4× MSAA. Sheets label the baseline on the left and offline A on the right.

## A2 — softer, wider nose cue and clearer lips (Codex, 2026-09-10)

Owner liked A1 but described its nose as a tiny spot and requested a slightly larger-looking nose and clearer lips. A2 stays material-only: the under-tip cue becomes a wider shallow arc with a lower peak opacity (0.19→0.13), accompanied by a soft side gradient and subtle bridge highlight. Existing lip pigment gets a wider mask and stronger warm definition; ears remain unchanged. No geometric enlargement is claimed. A1 shader and evidence are preserved; `face_a2.gdshader` is a separate candidate, not a replacement. Set `FACE_REVIEW_REVISION=A2` when running the same renderer to reproduce A2; leaving it unset still reproduces A1. Each A2 run generates both v1.3→A2 and freshly rendered A1→A2 comparison sheets under identical conditions.
